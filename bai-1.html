Thao tác cơ bản với tệp tin và thư mục
Đang thực hiện
a) Mục tiêu bài tập

Rèn luyện kỹ năng tạo, đổi tên, sao chép, di chuyển, xóa và khôi phục tệp tin, thư mục trên máy tính. Bài tập được thực hiện trên hệ điều hành Windows bằng File Explorer.

Kỹ năng rèn luyện: quản lý tệp bằng chuột và phím tắt, xây dựng cấu trúc thư mục khoa học và đặt tên tệp nhất quán để dễ tìm lại tài liệu học tập.

b) Tóm tắt quá trình thực hiện
  • Mở File Explorer
    Nhấn Windows + E, chọn This PC → ổ đĩa D để tiến hành lưu trữ tài liệu.
  • Tạo thư mục chính
    Chuột phải → New → Folder, đặt tên KhoDuLieu_HocTap_Giang.
  • Tạo tệp ghi chú
    Chuột phải → New → Text Document, đặt tên GhiChu.txt.
  • Đổi tên tệp
    Chọn GhiChu.txt → nhấn F2 → đổi thành GhiChu_HocTap.txt.
  • Tạo thư mục con và sao chép
    Tạo thư mục TaiLieu; chọn tệp → Ctrl + C → mở TaiLieu → Ctrl + V.
  • Di chuyển tệp
    Tạo tệp DiChuyen.txt → Ctrl + X → mở thư mục đích → Ctrl + V.
  • Tìm kiếm tệp
    Nhập tên GhiChu_HocTap vào ô tìm kiếm của File Explorer để xác định vị trí tệp.
  • Xóa và khôi phục tệp
    Nhấn Delete để đưa tệp vào Thùng rác; mở Recycle Bin → chuột phải vào tệp → Restore.
  • Xóa tệp vĩnh viễn
    Chọn một tệp thử nghiệm riêng → nhấn Shift + Delete → xác nhận xóa.
  • Kiểm tra và sắp xếp dữ liệu
    Sắp xếp tệp theo tên hoặc ngày sửa đổi; kiểm tra lại các thư mục và sao lưu tài liệu quan trọng.
