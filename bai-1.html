Thao tác cơ bản với tệp tin và thư mục
Hoàn thành
a) Mục tiêu bài tập

Rèn luyện kỹ năng tạo, đổi tên, sao chép, di chuyển, xóa và khôi phục tệp tin, thư mục trên Windows bằng File Explorer.

Việc xây dựng hệ thống thư mục khoa học giúp sinh viên quản lý tài liệu học tập có tổ chức, hạn chế thất lạc dữ liệu và tiết kiệm thời gian tìm kiếm. Tài liệu của sinh viên đại học gồm bài giảng, giáo trình, bài tập cá nhân, bài tập nhóm, hình ảnh, bản thiết kế và sản phẩm học thuật, nên cần cấu trúc thư mục phân chia rõ theo từng môn học và mục đích sử dụng.

b) Tóm tắt quá trình thực hiện
  • Mở File Explorer
    Nhấn Windows + E hoặc bấm biểu tượng thư mục màu vàng trên thanh tác vụ.
  • Truy cập ổ đĩa lưu trữ
    Cột bên trái chọn This PC → nhấp đúp ổ D: (nếu máy không có ổ D: thì dùng thư mục Documents trong ổ C:).
  • Tạo thư mục mới
    Chuột phải vào khoảng trống → New → Folder, đặt tên ThucHanh_DuongThiHuongGiang → Enter.
  • Mở thư mục vừa tạo
    Nhấp đúp ThucHanh_DuongThiHuongGiang, đây là nơi lưu các tệp trong quá trình thực hành.
  • Tạo tệp văn bản
    Chuột phải → New → Text Document, đặt tên GhiChu.txt.
  • Đổi tên tệp
    Chuột phải vào GhiChu.txt → Rename → đổi thành GhiChuQuanTrong.txt.
  • Tạo thư mục con
    Trong thư mục chính, chuột phải → New → Folder, đặt tên TaiLieu.
  • Sao chép tệp (Copy & Paste)
    Chọn GhiChuQuanTrong.txt → Ctrl + C → mở TaiLieu → Ctrl + V, kiểm tra tệp đã được sao chép.
  • Di chuyển tệp (Cut & Paste)
    Quay lại thư mục chính, tạo DiChuyen.txt → Ctrl + X → mở TaiLieu → Ctrl + V, kiểm tra tệp đã rời vị trí ban đầu.
  • Xóa tệp
    Trong TaiLieu, chuột phải GhiChuQuanTrong.txt → Delete, tệp được chuyển vào Thùng rác (Recycle Bin).
  • Xóa vĩnh viễn
    Chọn DiChuyen.txt → Shift + Delete → Yes để xóa vĩnh viễn.
  • Khôi phục từ Thùng rác
    Mở Recycle Bin → chuột phải GhiChuQuanTrong.txt → Restore, tệp trở về vị trí ban đầu.
Công cụ
File Explorer, Recycle Bin; chụp màn hình từng bước làm minh chứng (12 bước, có chú thích hình)
Sử dụng AI

Khó khăn

Cách giải quyết
Bật View → Show → File name extensions để thấy đuôi .txt; đọc kỹ hộp thoại xác nhận trước khi xóa vĩnh viễn
